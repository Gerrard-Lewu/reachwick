# Release gates

- Validate locked clean installation, types, lint, tests, production build, and publication scan.
- Exercise owner lifecycle, CSV errors, persistence, suppressions, schedules, and backup/restore.
- Review source, Git history, built assets, images, and dependency licenses for publication safety.
- Build and smoke test Linux AMD64 and ARM64 containers.
- Verify hosted HTTPS through the configured proxy or tunnel and rejected direct app-port access; record image digest and date.
- Enable private vulnerability reporting and branch protection on GitHub.
- Review SBOM, checksums, and release notes before manual v0.1.0 publication.

Unchecked items remain blockers. Do not claim a verified release based only on documentation.
