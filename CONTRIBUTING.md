# Contributing

Discuss substantial changes in a repository issue first; see the [project board](https://github.com/users/Gerrard-Lewu/projects/4) for current priorities. Keep pull requests focused and explain the resulting behavior and validation evidence. Use Node.js 24 and `npm ci`.

Run `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`, and `npm run check:release`. Cover meaningful behavioral changes. Schema changes need versioned migrations and recovery guidance. Never commit credentials, customer data, databases, or research captures.

Contributions are licensed under MIT. Follow CODE_OF_CONDUCT.md; report vulnerabilities privately through SECURITY.md.
